# Contributing (private draft)

This is an experimental extension and a pinned-source snapshot, not an upstream PX4 feature. Keep code-only changes separate from aircraft configuration and binary artifacts. Include reproduction and test evidence, and distinguish host tests, target builds and hardware observations.

Do not rewrite the frozen baseline. Proposed fixes should be reviewable commits with explicit rationale. Preserve upstream copyright/license notices and complete the file-level licensing review before public distribution.

Development used AI assistance. The human maintainer remains responsible for integration, review and submitted claims. A later upstream PX4 submission should follow the current contribution policy, including required AI-assistance disclosure and sign-off by the human submitter. Historical model identities are not inferred from the patch.

- https://github.com/PX4/PX4-Autopilot/blob/main/CONTRIBUTING.md
